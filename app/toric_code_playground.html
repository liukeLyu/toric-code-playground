You read a logical qubit by measuring a loop that wraps the torus. The loop gives +1 or −1. Hover a row to see its loop on the board.

Why it doesn’t matter which row the loop is on (and when it does)

Below, the same Z loop is measured on every row (top line) and every column (bottom line), left to right = row or column 0, 1, 2, …. Black = −1, grey 0 = no definite value. Hover a cell to see that loop.

The 4 ground states form a register of 2 logical qubits, |q₁q₂⟩. The start state |00⟩ is ψ₀. The Z loop along x reads q₁ and the Z loop along y reads q₂ (see the Measure tab). No measurement or error on a few edges can read or change them: they are stored in loops around the whole torus.

Hover a gate to see its path on the board. Apply does the whole loop at once; dragging it yourself on the board does the same.

Why a gate is a braid

In the |q₁ = 1⟩ part of the state an m has gone around the torus along y, so one unit of m flux threads the loop along x. Dragging an e around x encircles that flux and gives −1: the same e–m braiding phase as in Part 1. In the |q₁ = 0⟩ part there is no flux and no phase. So Z₁ is literally “braid an e around the flux in the hole”. X₁ creates that flux; Z₁ detects it with a phase.

Errors and protection

A stray Z or X on one edge makes an anyon pair (the energy goes up by 4). If the pair is removed by closing its string locally, the register is untouched: ⟨start|ψ⟩ = 1. An error only changes the stored qubits if its string wraps the torus, which takes at least L edges. A bigger torus means better protection. Error correction is the job of pairing up anyons by short strings before they wander that far.

What toric-code braiding cannot do

Toric-code anyons are abelian: braiding them only multiplies the state by ±1. That gives the Pauli gates X and Z above, and nothing more. There is no Hadamard and no entangling gate: from |00⟩ every move leaves the register in a single basis state, and from |+0⟩ it never becomes entangled. Entanglement already present is kept but only shuffled: from Φ⁺ the four gates only move you among the four Bell states (Z₁ gives Φ⁻, X₁ gives Ψ⁺). Try it.

Computing by braiding alone needs non-abelian anyons, such as Fibonacci anyons. There, many anyons share a degenerate space, and exchanging two of them applies a matrix on that space, not just a phase. Braids then approximate any gate.

The heat bath. Each sweep, every edge gets on average one attempt at a random X or Z. An attempt is accepted with probability min(1, e−ΔE/T): creating an anyon pair (ΔE = +4) succeeds with probability e−4/T; moving or annihilating anyons is free. The state stays a Pauli string times the start state, so this simulation is exact for this noise.

Reading the register. First the anyons must be removed. Decode joins the closest anyons by shortest strings (a simple greedy decoder). If a pair is joined the wrong way round the torus, the decoder itself completes a logical error. The dashboard shows what you would read if you decoded now.

Memory experiment. Start from a ground state, run the heat bath, and record the time of the first logical error. Without correction the anyons are only removed at readout; with correction they are removed every N sweeps, with N set by error correction below the board (every sweep if it is off). In both cases the memory counts as lost at the first sweep where decoding would give a logical error.

Why the two columns behave so differently

Without correction, thermal pairs keep appearing at rate ∝ e−4/T and then wander for free. Once enough anyons have piled up, the decoder can no longer tell which ones belong together, and it joins some the wrong way. A bigger torus has more places for pairs to appear, so it does not help: the memory time is set by T, not by L.

With correction every sweep, a pair is usually removed while its two anyons are still close. Correcting less often gives pairs more time to drift apart, and the advantage fades quickly: try every 5 or 10 sweeps. A logical error needs a pair to drift about L/2 apart between two corrections, which becomes rapidly less likely as L grows. So the protection really is topological, but only together with active error correction: the 2D toric code on its own is not a self-correcting memory. The reason is the energy barrier: a logical error only ever costs the +4 of one pair, whatever L is. A memory that protects itself at T > 0 needs a barrier that grows with L, as in the 4D toric code, where errors are membranes rather than strings.

    The model

    One qubit per edge. H = −Σv Av − Σp Bp, with the star Av = ∏ X on the 4 edges at a vertex and the plaquette Bp = ∏ Z around a square. All of them commute, each is ±1, and the ground states have all of them +1. So E − E₀ = 2 × (number of −1 stabilizers) = 2 × (number of anyons).

    What the ground state looks like

    In the Z basis (each edge |0⟩ or |1⟩), Bp = +1 means an even number of |1⟩ edges around every square: the |1⟩ edges form closed loops on the dual lattice. Av = +1 means flipping the 4 edges at a vertex (which adds a small loop) does not change the amplitude. So a ground state is an equal-weight superposition of all closed-loop pictures: a loop condensate.

    e and m in the wavefunction

    m (Bp = −1): an odd number of |1⟩ edges at that square. A loop ends there, and you can see it in every single picture.

    e (Av = −1): flipping the star at that vertex changes the sign of the amplitude. No single picture shows it; it is a sign twist between pictures. Use Inspect on an e to see the two pictures side by side.

    Braiding and the ground states

    Z and X on the same qubit anticommute. When an e goes around an m, its Z loop crosses the m's X string once, so the state picks up −1: ⟨start|ψ⟩ = −1.

    A string that wraps the torus is not a product of stabilizers. It maps one ground state to another: a logical operator. See the Gates tab.
